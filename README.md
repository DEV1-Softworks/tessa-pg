## Overview
Tessa is a Unity library that generates small, playable 2D levels by building rooms, connecting them, and painting Tilemaps.

## Installation
- If this repo is opened as a Unity project, the package is already embedded at `Packages/games.wethefreaks.tessa`.
- To add it to another project, use Unity Package Manager:
  - Add package from disk and select `Packages/games.wethefreaks.tessa/package.json`, or
  - Add by name if it is already available in your scoped registry.
